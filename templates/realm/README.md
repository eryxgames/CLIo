# Realm starter

The smallest complete CLIo realm: a village at a ford through sixteen seasons - stocks, families
set to works, weather told a season ahead, wolves and raiders that show themselves before they come.

```
python clio.py templates/realm
python -m engine.realm templates/realm     # a steward plays it: stands or falls, and the score
```

To start your own, copy this folder to `games/yourgame/` and edit `realms.json`. It then appears in
the launcher. "Realms" in `docs/AUTHORING.md` explains every key.

Unlike the demo games, this folder is covered by the Apache-2.0 licence of the engine: copy it, change
it, ship it, sell it. No credit required.
