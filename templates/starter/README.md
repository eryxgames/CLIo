# Starter game

The smallest complete CLIo game: one puzzle, two rooms, an ending.

```
python clio.py templates/starter
```

To start your own game, copy this folder to `games/yourgame/` and edit the JSON.
It then appears in the launcher. `docs/AUTHORING.md` explains every key.

Unlike the demo games, this folder is covered by the Apache-2.0 licence of the
engine: copy it, change it, ship it, sell it. No credit required.
